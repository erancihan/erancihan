# Review — chapter 04 (Designing the ECS)

**Persona:** pedagogy reviewer who reproduces every claimed console output.

**Verified:** 47.4% code, 26 blocks, largest teaching block 20, 100% anchored, lint
clean. `Entity.hpp`, `ComponentStore.hpp`, `World.hpp`, `Components.hpp` all
reconstruct **exactly**.

**What's right**
- The swap-remove derivation is the strongest in the guide so far, and it got
  *better* under verification (see finding 1). The reader writes the missing-repoint
  version, sees two entities share a slot, and gets the real lesson: the bug is
  invisible at the moment it is created and only surfaces when unrelated code claims
  the slot later.
- `overlaps()` as a named predicate rather than a bare `&`; the `enum class` /
  bitwise-operator tradeoff explained rather than just worked around.
- The `glm::quat{1,0,0,0}` w-first warning is the kind of thing that costs an hour.
- Deferred destruction's two `living` guards are each justified with the concrete
  case that needs them (same id queued twice by two systems in one frame).
- The dangling-pointer hazard is stated here and then *paid off* in chapters 10
  and 12, where it actually bites — so it reads as a promise, not a caveat.
- Deliberate breakage exposes the limits of the harness itself: removing `set`'s
  early return leaves all counts correct until you call `set` twice.

**Findings**
1. **The originally-written harness was wrong.** It removed one entity and read
   another, and claimed the buggy version printed `c : 20`. Running it showed the
   buggy version printed the *correct* value — the stale index read out of bounds
   into the vector's spare capacity and got lucky. Rewrote the harness to add a new
   entity after the remove, which makes the corruption deterministic and in-bounds
   (`c : 99`), and verified buggy vs canonical side by side. The corrected version
   also teaches a better lesson about delayed symptoms.
   *(An incidental trap found on the way: quoted `#include` searches the includer's
   directory first, so my first comparison silently compiled the buggy header twice.)*
2. *(fixed)* Two oversized blocks split, one illustration marker moved.

**Score: 9.5/10**
