# Review — chapter 06 (Buffers, memory & descriptors)

**Persona:** Vulkan practitioner who insists every quoted validation message be real.

**Verified:** 43.4% code, 21 blocks, largest 20 added lines, 100% anchored, lint
clean. The tree reconstructed from chapters 01–06 **builds and runs**, and the
checkpoint's claim — device + swapchain lines and nothing else — is observed.

**What's right**
- The derivation is a copy-paste slip (`writes[1]` cloned from `writes[0]`, type not
  updated) and it is **reproduced exactly**: the three quoted validation messages
  are the real output of the real mistake, captured by running it. The third one is
  the payoff — the driver itself states that 327,680 bytes exceeds
  `maxUniformBufferRange` (65,536), which independently proves the UBO-vs-SSBO
  choice the chapter made earlier on reasoning alone.
- `immediateSubmit`'s `vkQueueWaitIdle` is called out as the crudest sync in the
  project, correct *only* because it runs before the frame loop exists.
- The per-frame array split is read off the member list, with the concrete symptom
  of getting it wrong ("you'd see the camera jitter, and blame the camera").
- `vmaFlushAllocation` explained as the bug that is invisible on desktop precisely
  because desktop memory is usually coherent.
- Deliberate breakage — dropping `MAPPED_BIT` — is chosen because it *fails late*:
  startup succeeds, and the segfault arrives in chapter 08, five hundred lines away.

**Findings**
1. **A claimed derivation was wrong and was replaced.** The chapter originally
   derived the descriptor-pool size from a claimed `VK_ERROR_OUT_OF_POOL_MEMORY`.
   Running it showed the undersized pool succeeds silently — since Vulkan 1.1
   over-allocating is explicitly permitted, so neither the driver nor the layers
   complain. Replaced with the type-mismatch derivation, which is invalid usage and
   therefore reliably caught. The pool budget is still taught, now with an honest
   note that you cannot count on the layers here.
2. Chapter creates no files, only grows two — flagged in the header.

**Score: 9.5/10**
