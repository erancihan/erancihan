# Review — chapter 01 (Project setup & toolchain)

**Persona:** pedagogy reviewer who has watched beginners get lost in setup chapters.

**Verified:** `verify.py` — 23.1% code, 7 blocks, largest 19 added lines, **100%
anchored**, lint clean, reconstructs exactly `CMakeLists.txt` + `main.cpp` (the
illustration blocks correctly excluded). CMake fragments match the canonical build
file minus the source lines later chapters add, which is the intended state.

**What's right**
- Reading conventions come **first**, before any real snippet — the brief's §2g
  requirement, and the right call regardless: the reader learns to read a diff on
  a toy `struct` rather than on a Vulkan create-info.
- The two growing files (`main.cpp`, `Renderer.cpp`) are named up front, so
  repeated diffs against them read as intended rather than as repetition.
- The build file is split into three passes at real seams (find deps / target /
  shaders) instead of one 40-line paste. The shader pass genuinely deserves its
  own section — it is the only step a non-GPU C++ project wouldn't have.
- The checkpoint has an exact command, an exact expected result (`exit 0`), a
  symptom→cause table with five real failures, and a **deliberate breakage**: add
  a nonexistent source, watch CMake fail at configure time, take it back out.
  That breakage teaches precisely why the stub `main.cpp` exists.
- The file→chapter map is complete and includes the two files the original guide
  never mentioned (`GameState.hpp`, `VmaImplementation.cpp`).

**Findings**
1. *(fixed)* Both illustration blocks were being reconstructed as real files.
   Markers moved into the location line / preceding sentence so the verifier and a
   human reader agree on what is not to be typed.
2. The `glslc`/`glslangValidator` fork is explained rather than presented — a
   reader on Debian would otherwise hit `No GLSL compiler found` with no idea why
   the guide's SDK instructions didn't help.
3. Chapter is long (441 lines) but only 23% code; the length is the conventions
   section and the file map, both one-time costs that pay off for 15 chapters.

**Score: 9.5/10**
