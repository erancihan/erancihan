# (precedent: ch06/ch08/ch09 manifests do the same). fp32_add4_tree and

# regression compiles that exact file next to these.

# inside the harness's 60 s SIM_TIMEOUT; the chapter's 240,000-quadruple
# headline run is the same source at -DNQ=60000, re-run out of harness.
#
# There is no warn or xfail target: every composition trap this chapter
# teaches (cross-wired instance ports, an order-unfaithful reference, a
# dropped flag OR) compiles in total silence -- that is the point -- and
# each lives in the README's mutation record instead.
