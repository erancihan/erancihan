# Build-and-run manifest for chapter 5.
#
# Format, one target per line:
#   <expect> : <source files ...>
# where <expect> is
#   run   - must compile with zero iverilog output and the testbench must run to completion with
#           no FAIL anywhere in its output
#   xfail - must FAIL to compile; a deliberate teaching example
#
# Files named bad_*.v are deliberately wrong teaching examples. The two xfail
# ones are the SystemVerilog constructs Icarus cannot parse; the two run ones
# self-check, so PASS from a bad_* target means "the trap still reproduces on
# this simulator".
#
# Every target here runs with no plusargs, which is the mode that is supposed
# to be green. The interesting failures are behind plusargs and -D flags and
# are listed in README.md: +mode=ch04, +gen=uniform, +gen=narrow, -DBREAK_WRAP.
#
# No target writes a file. Lines starting with # are comments. The runner is
# ../run_all.sh.
