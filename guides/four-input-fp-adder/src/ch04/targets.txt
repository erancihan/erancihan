# Build-and-run manifest for chapter 4.
#
# Format, one target per line:
#   <expect> : <source files ...>
# where <expect> is
#   run   - must compile with zero iverilog output and the testbench must run to completion with
#           no FAIL anywhere in its output
#   xfail - must FAIL to compile; a deliberate teaching example
#
# Chapter 4 has no xfail target. Its two hard errors - $dumpvars on a memory
# array, and a literal seed passed to $random - are both rejected by vvp when
# it LOADS the program, not by iverilog, so neither fits either row. See the
# README.
#
# Files named bad_*.v are deliberately wrong teaching examples. They still
# self-check, so PASS from a bad_* target means "the trap still reproduces on
# this simulator".
#
# No target writes a file. Waveform dumping is behind a +dump= plusarg in
# every testbench that supports it, so a regression run leaves the tree clean.
#
# Lines starting with # are comments. The runner is ../run_all.sh.
